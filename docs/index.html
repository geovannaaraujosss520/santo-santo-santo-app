Importar novos produtos

Envie uma planilha .xlsx no mesmo modelo do sistema. Produtos com ID já existente são atualizados; os demais entram como novos. A coluna Foto_URL aceita link do Google Drive (com compartilhamento "qualquer pessoa com o link") ou qualquer link direto de imagem — a foto é aplicada automaticamente, sem precisar editar peça por peça depois.

Atualizar fotos em massa

Envie uma planilha simples com duas colunas — ID_Produto e Foto_URL — pra aplicar fotos em vários produtos de uma vez, sem mexer em mais nenhum dado deles. Aceita link do Google Drive (compartilhado como "qualquer pessoa com o link") ou qualquer link direto de imagem.
